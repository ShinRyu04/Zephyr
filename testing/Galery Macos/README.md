# Galery — tampilan macOS

Galeri foto desktop bergaya macOS Photos. Electron + HTML/CSS/JS polos,
tanpa framework dan tanpa dependensi selain Electron.

## Menjalankan

    npm install
    npm start

## Fitur

- Jendela tanpa frame dengan traffic light ala macOS
- Sidebar album, grid foto, dan viewer lightbox
- Pencarian foto dan pemilihan folder lewat dialog native
- Menu bar Electron bergaya macOS
