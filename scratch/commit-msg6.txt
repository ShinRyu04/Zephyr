feat(ai): panel detail model ala TRAE + deteksi kapabilitas vision

Panel detail (dua kolom) di picker model
- kiri: daftar model; kanan: panel "Available for" / Cost / Context
- muncul saat HOVER (dan keyboard focus), bukan klik: klik tetap memilih
  model dan menutup menu. Kalau klik yang mengisi panel, pembaca harus
  memilih model dulu untuk tahu apakah memilihnya ide bagus
- saat belum ada hover, panel menampilkan model yang sedang aktif
- komponen bersama ModelDetailPanel dipakai KEDUA picker (chat + subagent)
  supaya tidak jadi dua gaya seperti sebelumnya
- Memories: baris nonaktif berchip "Soon", tidak pernah dicentang, karena
  itu fitur Zephyr dan bukan kapabilitas yang dideklarasikan model

Deteksi vision/reasoning/tools
- deteksiKemampuan(): sumber API DULU (architecture.input_modalities,
  supported_parameters), lalu heuristik NAMA keluarga kalau provider diam
- tri-state: undefined = tidak dilaporkan, [] = diketahui tidak bisa,
  [...] = bisa. UI menggambar ketiganya berbeda supaya "tidak tahu"
  tidak terbaca sebagai "tidak bisa"
- KELUARGA_TEKS menang atas daftar vision, jadi deepseek-chat tidak
  ikut dicentang hanya karena daftar menyebut DeepSeek
- pricing TIDAK dihitung sebagai laporan kapabilitas: gateway yang
  melaporkan harga tapi bukan modalitas tetap "tidak dilaporkan"

Backend mengirim metadata, bukan cuma id
- list_models: Vec<String> -> Vec<ModelInfo> {id, input_modalities,
  supported_parameters, context_length, pricing}. Sebelumnya semua field
  ini diparse lalu DIBUANG, itulah sebabnya picker hanya bisa menampilkan
  nama + ukuran konteks
- parse data[].architecture.input_modalities, supported_parameters,
  context_length/top_provider.context_length, pricing (gaya OpenRouter,
  yang dipakai modelrouter.id). Gemini: inputTokenLimit saja
- semua field Option: None = "provider tidak bilang"

Kompatibilitas
- commands.ts: listModels mengembalikan ModelInfo[], normalisasi menerima
  array string lama maupun objek baru; listModelIds() untuk 4 pemanggil
  yang hanya butuh id
- settingsStore: remoteModels tetap string[] (6 konsumen tidak diubah),
  metadata baru di remoteInfo. Provider yang tidak melaporkan apa pun
  tidak diberi entri sama sekali

Customize Layout + garis pembatas digeser ke slot "Notes & todos"
- margin garis 28px -> 2px/-4px; klaster dikunci dari kanan, jadi tombol
  dan garis bergeser bersama: tombol x=1331, garis x=1367
