## Aturan umum (berlaku semua fase)

1. **Setiap fase berakhir dengan verifikasi** (V1..Vn) — jalankan & tunjukkan
   bukti. Lulus → commit.
2. `npx tsc --noEmit` = 0 error sebelum semua commit. `npm run tauri dev`
   (atau `build`) harus jalan.
3. Jangan menghapus fungsi yang sudah berjalan di fase sebelumnya.
4. Komentar singkat (id/en) DI DALAM kode di tempat penting.
5. Semua path Windows: Rust pakai `PathBuf`; frontend jalur string biasa.
6. Pesan commit: `zephyr: fase NN <nama>`.
7. Kalau ragu desain: baca `Zephyr PRD.md` + fase 01 lebih dulu.
8. Data user disimpan `%APPDATA%\zephyr\` — jangan hardcode path lain.
9. JANGAN pernah menampilkan/melog API key yang disimpan (mask).
10. Akhir: build release v1.0.0 (MSI + NSIS) + tag git + BUILD_REPORT.md.

Untuk detail implementasi penuh (komponen, commands, verifikasi) —
jalankan prompt di folder `Desktop\Ai\Zephyr\` sesuai urutan di atas.
