# Project Context - Zephyr

## Stack
- Tauri 2 (Rust, src-tauri/) + React 18 + TypeScript + Vite + Zustand (src/).
- Editor desktop; AI panel + agent loop di src/lib/aiStore.ts (~7000 baris).
- Streaming & adapter provider: src-tauri/src/ai.rs + src-tauri/src/adapters/{openai,anthropic,gemini}.rs
- Tool agent: src/lib/zephyrTools/builtins.ts (grep, glob, read_file, write_file, bash_run, ...).
- System prompt: src/lib/systemPrompt.ts.
- Harness verifikasi CDP: scripts/lib-cdp.mjs + scripts/uji-*.mjs.
