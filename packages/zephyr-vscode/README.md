# Zephyr AI Agent (VS Code & Trae Extension)

Autonomous AI Agent for VS Code & Trae with 7 Core Tools, Multi-Model Provider support, and Interactive Diff Editor.

## Features
- **7 Core Safe Tools**: `read_file`, `list_directory`, `glob`, `grep`, `write_file`, `multi_edit`, `ask_user`.
- **Zero Terminal Risk**: No shell/terminal execution for 100% safe workspace automation.
- **Multi-Model Provider Support**: Built-in support for Cartethyia, OpenCode2API, Geraikita, and OpenAI-compatible endpoints.
- **Interactive Diff Preview**: Review proposed code changes before applying them.
- **DeepSeek-R1 / QwQ Reasoning**: Live collapsible thinking stream.

## Installation
1. Open VS Code or Trae.
2. Go to the Extensions view (`Ctrl+Shift+X`).
3. Click `...` (More Actions) > **Install from VSIX...**
4. Select `zephyr-ai-agent-1.0.0.vsix`.
