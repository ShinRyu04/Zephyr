feat(ai): tool skill_view + dukungan katalog awesome-copilot

skill_view - tool yang selama ini dijanjikan prompt tapi tidak ada:
- skills.rs menyuntik daftar AVAILABLE SKILLS ke prompt dengan kalimat
  "read one with the skill_view tool", tapi tool itu tidak terdaftar di
  registry mana pun. Agent yang menuruti instruksi itu mendapat balasan
  "tool tidak ada" lalu berhenti atau mengarang isi skillnya.
- Terdaftar sebagai read-only ('read', bukan appWrite/exec): skill adalah
  bahan bacaan, dan gate yang bisa mematikannya akan meninggalkan agent
  memegang daftar skill yang tidak boleh dibukanya.
- Tanpa argumen name -> daftar skill; nama tidak ada -> saran nama mirip;
  nama tepat -> isi skill dipotong seperti read_file.

Katalog github/awesome-copilot:
- scripts/build-cc-catalog.mjs mengenal sumber keempat. Layoutnya sama
  dengan anthropics/skills (folder per skill berisi SKILL.md), jadi tidak
  perlu penanganan khusus.
- Field frontmatter yang tidak dikenal Zephyr (license, compatibility,
  metadata, argument-hint) sengaja TIDAK diteruskan: yang ditulis ke disk
  adalah body-nya, dan runtime pembaca membaca ulang frontmatter file itu
  sendiri.
- Teruji dengan 3 skill + 1 agent contoh: 7 entri, sumber terbaca benar.
